Only assets that are displayed as **Free** on Fab at acquisition time may be used. Prefer content packs over runtime plugins and verify the listing immediately before acquisition because price, compatibility and license metadata can change.

## Road production policy

Do not search for or import a large modular road pack unless the generated-road prototype fails quality or performance validation.

The planned road system should be generated from authored layout data and should support:

- primary and secondary road widths;
- intersections;
- sidewalks/curbs generated from the same layout;
- district-specific surface dressing;
- deterministic rebuilds;
- NavMesh-safe walkable surfaces;
- vehicle wreck placement and roadblocks;
- later decal layers for cracks, grime, snow, leaves and blood.

This keeps city topology under project control and prevents the level layout from being constrained by a third-party road kit.

## Deferred environment packs

Do not acquire Spring/Summer/Winter vegetation or seasonal packs yet. First complete the street-prop/asphalt batch and generate the asset review gallery. Seasonal environment acquisition should happen only after the architecture and world-layout prototype proves the actual remaining visual gaps.

`Soul: City` and `Electric Dreams Env` remain optional references, not current requirements.

## AI / license safeguard

- do not upload downloaded source meshes, textures or source files into external generative-AI services unless the applicable listing/license explicitly permits that use;
- automated Unreal Editor scripts may reference locally imported assets by exact Unreal object path;
- retain Fab listing IDs and acquisition records in this documentation;
- never redistribute standalone Fab source assets from the repository when the applicable license forbids standalone redistribution.

## Import policy

Do not move or rename imported Fab content after adding it to the project. Packs may depend on their original package paths.

After the next acquisition batch:

1. let Unreal finish shader/mesh/material processing;
2. run only the lightweight inventory script;
3. rebuild the classified environment catalog;
4. rebuild the production shortlist;
5. commit the generated audit/catalog files;
6. then generate the Unreal visual-review gallery;
7. only visually approved assets may enter the final generation manifest.

## Pack rejection rules

Reject an asset when:

- Fab no longer displays it as Free;
- its license cannot be verified;
- it requires a proprietary runtime plugin;
- it cannot be used with the local Unreal 5.5.4 project;
- it contains only renders and no usable UE/source delivery;
- it creates an unacceptable performance cost without an optimization path;
- it forces replacement of existing ZombieSeasons gameplay systems.
